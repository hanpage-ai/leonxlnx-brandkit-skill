# leonxlnx-brandkit-skill

> 브랜드 전략부터 로고, 비주얼 모드까지 — 프리미엄 아이덴티티 보드 한 장.

## 이 스킬의 역할

"브랜드 킷 하나 만들어줘"라고 하면 산발적인 로고 + 무작정 붙인 목업이 나올 때,
이 스킬은 **프리미엄 아이덴티티 스튜디오의 보드**를 한 장에 뽑아줍니다.

- 3×3 (또는 커스텀) 그리드 보드 — 로고, 컬러, 타이포, 디지털/피지컬 목업
- 브랜드 전략(카테고리, 오디언스, 코어 메타포)을 먼저 정리한 뒤 비주얼
- 로고 컨셉 5가지 방법 + 9가지 비주얼 모드로 톤을 끝까지 일관 적용

## 누가 쓰면 좋은지

- **브랜딩 프리랜서 / 디자이너**: 클라이언트 컨셉 단계에서 아이덴티티 보드를 빠르게 보여주고 싶을 때
- **스타트업 / 프로덕트 팀**: 로고 + 컬러 + 타이포 + 목업을 한 장의 발표 자료로 정리할 때
- **AI 이미지 생성 활용자**: "로고"가 아니라 "브랜드 시스템"으로 요청의 질을 올리고 싶을 때
